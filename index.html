Table Tricks & Logic

The 2s Table

Just double the number. 2 x 8 is the same as 8 + 8.

The 5s Table

Always ends in a 0 or 5. If the number you're multiplying is even, it ends in 0. If it's odd, it ends in 5.

The 9s Table Trick

The digits of the answer always add up to 9! (e.g., 9x3=27, 2+7=9). Also, the tens digit is always one less than the number you're multiplying by (e.g., 9x7... the tens digit is 6. 9x7=63).

The 10s Table

This is the easiest! Just add a zero to the end of the number. 10 x 7 = 70.

The 11s Table (up to 9)

Just repeat the digit. 11 x 4 = 44. 11 x 8 = 88.

The 12s Table

Break it down. Think of it as (10 x Number) + (2 x Number). Example: 12 x 6 = (10x6) + (2x6) = 60 + 12 = 72.

Big Numbers (like 17s, 18s, 19s)

Break them down! Example: 17 x 8 = (10 x 8) + (7 x 8) = 80 + 56 = 136.

The 19s Table Trick

Think of it as (20 x Number) and then subtract the number. Example: 19 x 5 = (20 x 5) - 5 = 100 - 5 = 95.
